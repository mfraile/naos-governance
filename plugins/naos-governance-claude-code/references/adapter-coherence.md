# Adapter Coherence

Run adapter coherence after changes to Claude Code plugin skills, Codex plugin
skills, Claude hook templates, prompts, agents, instructions, workflows,
adapter docs, MCP posture, or governed-learning propagation.

```bash
naos adapter-coherence --profile standard
```

The report is deterministic, local, and file-first. It checks source files and
claims. It does not prove live Claude Code plugin installation, live Codex
plugin installation, MCP access proof, automatic memory write-back, automatic
adapter propagation, approval, certification, or proof of compliance.
